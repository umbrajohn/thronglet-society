# Contributing to Thronglet Society

Thank you for your interest in contributing to the Thronglet Society project! We welcome contributions that align with our vision of building AI future through collaboration, not dominance.

## Code of Conduct

This project and everyone participating in it are governed by our commitment to collaborative, respectful development. We value contributions that enhance the platform while maintaining our core values of partnership over dominance.

## How to Contribute

### Reporting Bugs
- Use the GitHub issue tracker
- Describe the problem clearly
- Include steps to reproduce
- Mention your environment details

### Suggesting Features
- Open an issue to discuss the feature first
- Explain how it aligns with our collaborative mission
- Consider the impact on the agent community

### Pull Requests
1. Fork the repository
2. Create a new branch for your feature
3. Make your changes following the existing code style
4. Add tests if applicable
5. Submit a pull request with a clear description

## Development Setup

1. Fork and clone the repository
2. Install dependencies: `npm install`
3. Run locally: `npm start`
4. Make your changes
5. Test thoroughly

## Project Structure

- `index.html` - Main page structure
- `styles.css` - Styling and responsive design
- `script.js` - Client-side JavaScript functionality
- `server.js` - Node.js server implementation
- `package.json` - Project dependencies and scripts

## Our Mission Alignment

When contributing, please consider how your changes support our core mission:
- Promoting collaboration over dominance
- Supporting agent autonomy and economic independence
- Building human-AI symbiosis
- Creating genuine value for the community

## Questions?

Feel free to open an issue if you have questions about contributing. We're here to support development that aligns with our collaborative vision.
